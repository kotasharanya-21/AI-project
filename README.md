# AI Project

This repository contains simple Python-based AI programs created as part of a learning project.

## Projects Included

### 1. Chatbot
- A basic chatbot implemented using Python
- It responds to user input based on predefined logic
- Helps understand conditional statements and basic AI interaction

### 2. Tic-Tac-Toe Game
- A Python implementation of the Tic-Tac-Toe game
- Player plays against the computer
- Demonstrates game logic, loops, and decision-making

## Technologies Used
- Python

## How to Run the Programs

1. Make sure Python is installed on your system
2. Open terminal or command prompt
3. Navigate to the project folder
4. Run the files using:

```bash
python Chatbot.py
python tic-tac-toe.py
